# Product

## Register

product

## Users

HyperDataLab students, researchers, lecturers, and staff with a verified `@hyperdatalab.org` account. They use the file space while working on research and publication tasks.

## Product Purpose

Research Hub provides a focused place to create research projects and manage research files. Project metadata is stored in Cloud Firestore and file content in private Cloudflare R2; stable project IDs are the future integration point for PaperLab and Writing.

## Brand Personality

Professional, clear, trustworthy. The interface should support focused academic work and feel consistent with the HyperData Lab and ResearchPulse products.

## Anti-references

Avoid flashy visuals, decorative dashboard patterns, heavy surfaces, generic file-manager branding, and controls that look interactive but do not work.

## Design Principles

- Keep research files and their actions central.
- Treat projects as the stable, module-neutral workspace foundation for future research tools.
- Use the shared HyperData Lab visual system consistently.
- Make access state, upload progress, and file status easy to understand.
- Preserve dependable interactions across desktop and mobile.

## Accessibility & Inclusion

Support keyboard interaction, clearly visible focus, readable contrast, and responsive layouts. Respect reduced-motion preferences.
